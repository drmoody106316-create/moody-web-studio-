# Module 2 – Content Audit, Style Guide, Sitemap, Mock Pages & Wireframes

## Module Purpose
Module 2 focuses on planning the structure, content, and visual direction of the website. This includes auditing all content, defining the design system, mapping out the site structure, and creating wireframes and mock page outlines before moving into the design phase.

## What Was Completed
- Full content audit for all pages (Home, About, Services, Gallery, Booking)
- Updated 5‑page website structure
- Completed Style Guide (colors, typography, spacing, imagery rules)
- Created Sitemap showing page hierarchy and navigation flow
- Wireframes for each page
- Mock page outlines to guide layout and content placement
- Added Booking Page to the site structure
- Identified items to keep, revise, or redesign across all pages

## Files Included in This Module
- content-audit/
- style-guide/
- sitemap/
- wireframes/
- mock-pages/
- README.md

## How This Module Supports the Project
Module 2 establishes the foundation for Module 3 by defining the website’s structure, visual identity, and layout. With the content audit, style guide, sitemap, mock pages, and wireframes completed, the project now has a clear blueprint for creating polished mockups and final designs.
