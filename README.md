The purpose of this project is to develop a fully functional web application that demonstrates industry‑standard development practices, modern integration techniques, and professional client‑facing deliverables. This module focuses on implementing third‑party APIs, enhancing user experience through dynamic features, and ensuring the application handles external data securely and gracefully. The project showcases proficiency in front‑end and back‑end development, API consumption, error handling, responsive design, and client communication.
The intended outcome is a complete, well‑documented web solution for Ariana Flores — Pro Sports Photography, featuring a booking system, user authentication, integrated Google Maps, location‑based weather, and a polished client approval workflow. This module also includes a written presentation, a video demonstration, and formal sign‑off documentation to meet the technical and communication standards outlined in the course.
